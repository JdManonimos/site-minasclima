# Ativar as avaliações do Google Maps

A seção funciona no GitHub Pages. Enquanto a chave e o identificador da ficha estiverem em branco, a seção mostra apenas o link para o Google Maps e não faz consultas à API de avaliações. Quando configurada, a consulta ocorre ao clicar em **Ver avaliações aqui**.

1. Use um projeto do Google Cloud da empresa com faturamento habilitado e ative **Maps JavaScript API** e **Places API (New)**. A leitura de avaliações é faturável conforme o uso. Confira a [tabela de preços](https://developers.google.com/maps/billing-and-pricing/pricing).
2. Crie uma chave exclusiva de navegador. Em **Restrições de aplicativo**, escolha **Sites** e permita https://jdmanonimos.github.io/* ou a origem do domínio oficial quando configurado. O navegador pode enviar somente a origem no referenciador, por isso a restrição usa a origem do site. Em **Restrições de API**, permita somente **Maps JavaScript API** e **Places API (New)**. A chave de navegador é pública. Use somente a chave com essas restrições, nunca uma chave de servidor. [Restrições recomendadas pelo Google](https://developers.google.com/maps/api-security-best-practices#recommended-api-restrictions).
3. No [localizador oficial de Place IDs](https://developers.google.com/maps/documentation/javascript/examples/places-placeid-finder), procure a Minas Clima em Uberlândia e confira que o resultado corresponde à ficha compartilhada pelo [link usado no site](https://maps.app.goo.gl/dXToyWgzQPiQCbig9). Copie o **Place ID**, que é diferente do link curto e de um CID.
4. No elemento com id avaliacoes em index.html, preencha data-google-key com a chave restrita de navegador e data-place-id com o identificador conferido. Teste pela origem HTTP(S) autorizada.
5. Para disponibilizar o recurso publicamente, inclua links para os termos e a política de privacidade da empresa, incorporando os links exigidos pelo Google, conforme a [documentação de políticas e atribuições](https://developers.google.com/maps/documentation/javascript/policies). Confira a ficha de origem e as atribuições de autores e fornecedores no teste com a API real.

A integração exibe as avaliações devolvidas pela API com a autoria disponível. A consulta mantém o conteúdo apenas na página aberta. Se o carregamento falhar ou não retornar avaliações com autoria, o visitante ainda tem o link para a ficha no Google Maps.
